# Linux–FPGA 数字基带与 DFE

面向 FPGA、数字设计和基带工程岗位的 AX7A200B / Artix-7 项目作品集。

[English](README.md) · [验证摘要](docs/validation-summary.md) · [工程案例](docs/engineering-highlights.md)

## 已实现的结果

Linux 主机通过以太网下发已保存的 OAI 下行任务，FPGA 执行受限配置的 NR 基带与数字前端处理，在板内完成数字样点消费，再回传完整 I/Q 结果，与参考结果逐比特比较。

**已通过一批实板能力验收：18 项任务全部完成，450,000 对复数 I/Q 样点全量一致。**

这证明了有限范围内的 Linux–FPGA 数字处理闭环，不代表完整实时 5G 基站已经完成。可交付的 Version 1 运行流程仍在推进，尚未发布。

## 系统路径

Linux 任务准备 → 以太网传输 → FPGA 基带 / DFE → 板内数字消费 → 完整结果回传与核验

处理范围包含信道编码、速率匹配、资源网格、OFDM 和 DFE。这里使用保存的任务进行回放，不等于在线替换 OAI 软件 PHY。

## 工程能力展示

- 数字设计：RTL 集成、跨时钟域处理、复位、握手、背压与综合后调试。
- 基带与 DFE：定点参考结果比较，以及受限配置的完整数字处理链验证。
- 主机与硬件协同：任务生命周期、有界重试、全量回读和资源释放。
- 验证方法：参考模型、RTL、网表与实板分层验证，包含负向测试、故障注入及失败证据保留。
